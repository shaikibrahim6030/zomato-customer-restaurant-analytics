# 🍽️ Zomato Customer & Restaurant Analytics

## 📌 Project Overview

This project focuses on analyzing Zomato restaurant datasets to uncover customer preferences, restaurant performance trends, cuisine popularity, pricing behavior, and online delivery adoption patterns.

Using Python and data analytics techniques, the project transforms raw restaurant data into actionable business insights that can support decision-making in the food-tech and restaurant industry.

The analysis combines Exploratory Data Analysis (EDA), customer analytics, restaurant performance evaluation, and interactive visualizations to identify key factors influencing customer satisfaction and restaurant success.

---

## 🎯 Business Objectives

The primary objectives of this project were:

* Analyze customer preferences and restaurant trends.
* Identify popular cuisines and pricing patterns.
* Evaluate restaurant ratings and customer satisfaction.
* Understand online delivery and table booking adoption.
* Discover geographical and regional food trends.
* Generate actionable business insights through data visualization.
